BIRTHDAY CAKE ARCHERY GAME

This is a standalone playable birthday mini-game.

GAMEPLAY
- Click START GAME.
- Aim the bow with your mouse.
- On mobile, drag/aim with your finger.
- Release/click to shoot.
- Hit the cake with an arrow.
- When the cake is hit, a full-screen Happy Birthday animation appears.

CUSTOMIZE THE NAME
Open script.js and change:

const CONFIG = {
  birthdayName: "HER NAME"
};

Example:
birthdayName: "Maria"

No other code needs to be changed.

OPTIONAL
You can replace the emoji cake with your own artwork later, but the game already works without extra files.
